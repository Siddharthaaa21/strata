Space Grotesk for UI, Source Serif 4 for document titles and long-form body, ui-monospace for the
one code block. Sizes are deliberately non-round (11.5/12.5/13.5/17/17.5/18.5/26/34px) — never
round them. The reader body grows on mobile while everything else shrinks.
